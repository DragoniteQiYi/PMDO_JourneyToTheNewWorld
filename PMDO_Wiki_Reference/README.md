# PMDO Wiki 离线参考

本目录保存了 PMDO（Pokémon Mystery Dungeon: Origins）Modding Hub 的关键文档，
抓取自 https://wiki.pmdo.pmdcollab.org/Modding_Hub ，用于离线查阅。

> 注意：正文中的链接若指向本目录内已有的页面会跳到本地文件，
> 其他链接仍指向在线 Wiki。图片未下载，离线时可能不显示。

## 建议学习路径

1. 先看 `Modding Hub` 与 `Tutorial:Index` 了解整体结构。
2. 新手从 `Tutorial:Creating a Mod` 与 `Tutorial:Getting Started With Git` 开始。
3. 学会后重点阅读脚本部分：`Global Lua Functions`、`Lua Function Reference`、
   `Tutorial:Scripting Cheat Sheet`，以及 `Tutorial:Basic Zone Scripts`、`Tutorial:Coroutines in Scripts`。
4. 制作内容时按需查阅地牢、地图、图形、游戏机制等章节。
